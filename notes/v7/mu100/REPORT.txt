QUANTITIES
  GS   : A_mu on Z_h = ker B                    (paper tab:thresh)
  EFF  : A_mu - C^T M^-1 C on Z_h               (= N_h - m_h, the effective-penalty form of notes/v7/robust; its Schur form)
  CNS* : the actual saddle [A_mu, -(B - Cm)^T; B, 0], Cm mean-corrected exactly as svn.coupling / solve_direct.
         On Z_h it is Petrov-Galerkin (trial ker B, test ker(B - Cm)), nonsymmetric, so there is no inertia/coercivity
         threshold in the strict sense.  The stability quantity is mu_c^CNS = largest real mu at which the square
         system is singular (shift-invert eigen-mu of the pencil).  Probing at sigma = 300 finds no singular mu in
         (100, 500]; the nearest eigen-mu to sigma=300 are the same ones near 80-88.
  gamma = mu / rho, rho = h / h_Gamma.

INERTIA CHECK (ldl.log, N = 8, dense symmetric saddle [[K, B^T],[B, 0]], rank B = 320 = #pressure dofs)
  GS : mu = 40: 324 neg;  mu = 50: 320 neg + 4 zero (mu* = 50.28);  mu >= 60: exactly 320 neg.
  EFF: mu = 40: 331 neg;  mu = 50: 327 neg;  mu >= 60: exactly 320 neg (mu*_EFF = 58.12).
  Agrees with the pivot-sign bisection.  At mu = 100 every GS and EFF run has 0 negative pivots on Z_h (N = 8..64; 128 for GS/EFF).

VERDICT
  mu = 100 is above mu_c^CNS on every production mesh.  The margin is 38% (N=8), 27% (16), 22% (24), 19% (32), 15% (48),
  13% (64), and it SHRINKS with N: in the limit it is about 7% in mu, or gamma 28.6 vs 26.5, about 2 units.  The production
  runs are stable but not by a wide margin.  The paper should not describe mu = 100 as "comfortably" above the threshold
  for CNS*.  For GS the corresponding margin is about 34% in the limit (21.4 vs 28.6).

RESOLUTION OF THE TENSION (why "30 - (10..27) <= gamma*_GS" was the wrong comparison)
  1. The GS threshold gamma* ~ 18-21 is set by a TANGENTIAL mode.  crit_modes.log: the GS critical mode's wall trace is
     only 0.4-1.3% normal (fn = 0.013 at N = 16, 0.004 at N = 32).  m_h acts only on u.n, so it removes 0.2-0.75% of the
     penalty on that mode.  Subtracting m_h therefore hardly moves the GS-type instability.
  2. The EFF and CNS* critical mode is a DIFFERENT family: almost purely normal (fn = 0.99), edge-mean dominated
     (fnm = 0.90-0.97).  On it m_h equals the whole normal penalty (m_h / ((mu/h)||u.n||^2) = 1.01-1.11 at mu_c), so the
     sharp constant k(k+1)/H_e is attained there.  These normal modes are stable in GS down to far smaller gamma.  They
     go critical when the LOCAL effective penalty (mu/h - 20/H_e) h_Gamma on the thinnest-first-layer edges
     (H_e/|e| ~ 0.75) reaches about 0 to -1, not when it reaches gamma*_GS.
     At mu = 100 that local effective penalty is +2.9 to +5.3 (N = 64..16; cns_crit.log gamma_eff100_range min),
     about +2 in the limit.  Hence stability, with a small margin.
  3. The xi-tilde / nonsymmetric coupling does not "restore" coercivity.  It changes the threshold by +14.2 (N=8),
     +7.5 (16), +3.6 (32), +1.8 (64) in mu relative to EFF, and the CNS* and EFF limits coincide (~26.5).  The
     effective-penalty picture of notes/v7/robust is correct.  What was wrong was comparing a uniform shift 10-27
     against the tangential-mode threshold gamma*_GS.
  Suggested rewording of the remark: "m_h removes the normal penalty on edge-mean normal modes; the resulting CNS*
  threshold is gamma_c ~ 26.5 (mu_c ~ 93 in the limit; 72-88 on N = 8-64), below the production gamma(100) ~ 28.6-30.5,
  which is therefore stable, with a margin that decreases from 27% (N = 16) to about 7% as h -> 0."
